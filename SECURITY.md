# Security policy

Report vulnerabilities, leaked audio/identity data, exposed credentials or unsafe decoder behaviour through GitHub private vulnerability reporting. If unavailable, contact an organisation owner privately. Do not attach private recordings, secrets or impersonation-ready samples to public issues.

The planned upload service must isolate media decoding, verify content types, bound duration/size/resources, restrict storage access and implement retention/deletion. No inference service is currently released.

Only current main is supported before a tagged release. Synthetic-speech scores are research signals, not evidence of fraud or a person's identity.
