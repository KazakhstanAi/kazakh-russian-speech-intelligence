# KZ/RU Anti-Spoofing Benchmark

Planned R&D infrastructure for VAIS Voice, not a standalone product or a released dataset.

Use licensed genuine/synthetic audio, protected speaker/source/generator partitions, matched channel transforms and separate calibration data. Report ROC-AUC, EER, FPR@TPR95, operational error rates, calibration and abstention by language, generator and channel. See [evaluation protocol](../docs/evaluation-protocol.md) and [data governance](../docs/data-and-ethics.md).

This directory currently documents the contract only. It does not contain a corpus or evaluation implementation.
